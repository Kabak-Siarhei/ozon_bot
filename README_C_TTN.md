# c_ozon_ttn

Консольная утилита на чистом Си (C11) для добавления интерактивных
AcroForm-полей (текстовых полей формы) в PDF-документы ТТН (Товарно-транспортная
накладная). Использует библиотеку MuPDF (mupdf-c).

Логика перенесена из Rust-проекта `ozon_bot/src/pdf.rs`.

**Нет зависимостей от Python.** Только MuPDF + стандартная библиотека Си.

## Возможности

- Добавляет 5 стандартных полей ТТН с настраиваемыми координатами, именами и значениями:
  - Автомобиль
  - Водитель
  - Отпуск разрешил
  - Сдал грузоотправитель
  - Товар к перевозке принял
- Поддержка INI-файла конфигурации (`-c settings.ini`) для удобного редактирования
  значений без перекомпиляции.
- Поддержка добавления одного кастомного поля с произвольными координатами.
- Корректное управление памятью: все контексты MuPDF (`fz_context`, `pdf_document`)
  инициализируются и освобождаются в блоках `fz_try / fz_catch`.
- Только стандартная библиотека Си + API MuPDF (нет лишних зависимостей, в том числе
  нет зависимостей от Python).

## Сборка

### Требования

- gcc / clang
- MuPDF (mupdf-c) — заголовки и разделяемая библиотека, установленные в системе
- Стандартная библиотека Си (libc)

### Команды

```bash
cd c_ozon_ttn

# Если MuPDF установлен в стандартные системные пути (/usr/local)
make

# Если MuPDF в нестандартных путях:
make MUPDF_INC=/opt/mupdf/include MUPDF_LIB=/opt/mupdf/lib
```

### Пример для macOS (если MuPDF установлен через Homebrew)

```bash
brew install mupdf
make MUPDF_INC=$(brew --prefix mupdf)/include MUPDF_LIB=$(brew --prefix mupdf)/lib
```

### Пример для Linux (Debian/Ubuntu)

```bash
sudo apt-get install libmupdf-dev
make
```

## Использование

### Режим по умолчанию (5 полей ТТН из INI)

```bash
./ttn_add_field in.pdf out.pdf -c settings.ini
```

Если ini-файл не указан, используются значения по умолчанию (из `default_value`).

### Режим одного поля

```bash
./ttn_add_field in.pdf out.pdf 65 170 265 180 "Автомобиль" "BMW X5 A123BC"
```

Аргументы: `x0 y0 x1 y1 имя_поля значение` — координаты в точках PDF
(отсчёт Y от верхнего края страницы).

## Формат settings.ini

```ini
[fields]
Автомобиль = BMW X5 A123BC
Водитель = Иванов Иван Иванович
Отпуск разрешил = ИП Кабак Сергей Анатольевич
Сдал грузоотправитель = ИП Кабак Сергей Анатольевич
Товар к перевозке принял =
```

- Ключи без значения (например, `Товар к перевозке принял =`) означают пустое
  поле в PDF.
- Если ключ отсутствует в ini — используется значение по умолчанию из кода.
- Комментарии начинаются с `#` или `;`.

## Сборка Docker-образа (для Render и других серверов)

```bash
docker build -t ttn_add_field .
docker run --rm -v $(pwd)/settings.ini:/app/settings.ini \
    -v $(pwd)/in.pdf:/app/in.pdf \
    ttn_add_field in.pdf out.pdf -c settings.ini
```

Образ собирается на Alpine Linux без каких-либо зависимостей от Python.

## Требования к runtime

- `libmupdf.so` (или `.dylib` на macOS) — разделяемая библиотека MuPDF
- `libz`, `libjpeg`, `libcrypto` (зависимости MuPDF)

## Лицензия

Поддерживает ту же лицензию, что и MuPDF (AGPLv3 или коммерческая лицензия Artifex).
